# 로또

> 간단한 로또 발매기를 구현한다.

## 기능 목록

## 1. 입력


### 1) 로또 구입 금액 입력

```
구입금액을 입력해 주세요.
> 14000
```

- 1,000 단위로 입력
- 천 단위 구분 쉼표(,) 입력 허용
    - ex) `1,000`, `14,000`

**1-1) 예외 처리 항목**

- 입력 값이 비어있는 경우
- 숫자와 쉼표를 제외한 다른 문자가 포함된 경우
- 입력 값이 0 이하인 경우
- 1,000으로 나누어 떨어지지 않는 경우
- 천 단위 구분 쉼표의 위치가 올바르지 않을 경우
    > `IllegalArgumentException`을 발생시키고 에러 메세지 출력 후 다시 입력 받는다
  

### 2) 당첨 번호 입력

```
당첨 번호를 입력해 주세요.
> 1,2,3,4,5,6
```

- 쉼표로 구분된 로또 번호를 입력받는다.

**2-1) 예외 처리 항목**

- 입력 값이 비어있는 경우
- 쉼표로 구분된 값이 비어있거나 정수가 아닌 경우
- 쉼표로 구분된 값이 6개가 아닌 경우
- 쉼표로 구분된 값이 1~45 범위에 있지 않은 경우
- 중복된 숫자가 입력된 경우
    > `IllegalArgumentException`을 발생시키고 에러 메세지 출력 후 다시 입력 받는다

### 3. 보너스 번호 입력

```
보너스 번호를 입력해 주세요.
> 7
```

**3-1) 예외 처리 항목**

- 입력 값이 비어있는 경우
- 정수가 아닌 경우
- 입력 값이 1~45 범위에 있지 않은 경우
- 당첨 번호와 중복된 숫자가 입력된 경우
    > `IllegalArgumentException`을 발생시키고 에러 메세지 출력 후 다시 입력 받는다

## 2. 로또 발행


### 1) 로또 구매 개수

- 구입 금액을 1,000으로 나눈 몫
- 천 단위 구분 쉼표가 있는 경우 변환하여 계산
    - `1,000` → `1000`, `14,000` → `14000`

### 2) 로또 발행

- 구매 개수만큼 로또를 발행한다.
- 로또 발행 시 중복되지 않는 6개의 랜덤 숫자를 뽑는다.
    - Random 값 추출은 `camp.nextstep.edu.missionutils.Randoms`의 `pickUniqueNumbersInRange()`를 활용한다.
- 로또 번호는 오름차순 정렬한다.

## 3. 로또 결과


### 1) 당첨 내역

- 구매한 로또와 당첨 번호를 비교하여 당첨 결과 계산
- 당첨 기준 및 금액
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원

### 2) 수익률 계산

- 수익률: `(총 당첨 금액)/(구입금액) * 100`
- 소수점 둘째 자리에서 반올림한다.

## 4. 출력


### 1) 발행한 로또 수량 및 번호 출력

```
3개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
```

### 2) 당첨 내역 출력

```
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
```

### 3) 수익률 출력

```
총 수익률은 62.5%입니다.
```

### 4) 에러 문구 출력

```
[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
```

- 에러 문구는 `[ERROR]` 로 시작해야 함.
